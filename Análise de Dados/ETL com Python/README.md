# API de Gerenciamento de Usuários Bancários

## Objetivo
API REST para gerenciar usuários, contas e cartões para desafio ETL.

O que é REST?

**Represnetational State Transfer**: É um designe de arquitetura de API. A sigla REST traduzida significa - Transferência de Estado Representacional. REST é um conjunto de regras e diretrizes sobre como deve ser criada uma API web. 

Mas o que é API? É o conjunto de definições e protocolos no desenvolvimento e integração de aplicações de software. 

A melhor palavra para descrever uma API é `contrato`. O objeto deste contrato é informação. Nas clausulas deste contrato o contratante precisa dar insumos para que o contratado forneça as informações. Assim, a parte contratada (servicor) pode requerer algum dado para que a resposta seja fornecida ao contratante (cliente).
